Криптосистема Рабина

Каждый байт файла m ∈ [0, 255] шифруется формулой c = m * (m + b) mod n, где n = p * q. Зашифрованные значения могут превышать 255, поэтому файл сохраняется как текст из чисел в десятичной СС, разделенных пробелами.

Дешифрование сводится к нахождению квадратного корня дискриминанта D = b * b + 4c по модулю составного числа n через китайскую теорему об остатках. Из 4 полученных корней выбирается единсвенный, дающий байт в диапазоне [0, 255].
